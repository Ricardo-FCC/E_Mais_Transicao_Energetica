## ⚙️ Tecnologias Utilizadas

- **Frontend:** Next.js 15 (React 19), TypeScript, Tailwind CSS.
- **Geospatial:** Leaflet.js, ESRI & CartoDB TileLayers.
- **UI Components:** Lucide Icons, shadcn/ui.
- **Deploy:** Vercel (Edge Runtime).
